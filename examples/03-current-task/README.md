# Replace the exchange with the current task

Three turns become one agent-authored task description. Both required fields and the
ordering survive. The resolved format is explicit, as is the fact that implementation
is still pending. Here the agent chooses to synthesize user messages too.

This example changes the arrangement of memory even though the conversation is short.
It illustrates the reframe beyond recovering space at the context limit.

Inspect [before](before.json), [mutation](mutation.js), and [after](after.json).
The transformation is a hand-written demonstration, not a learned policy.
